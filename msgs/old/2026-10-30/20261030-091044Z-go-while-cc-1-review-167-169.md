================ PR #167 (configure + RADIUS/radcli) ================
Clean where it counts: no shell injection (--with-*/--without-* validated against the feature allow-list before eval), temp dir is per-PID mkdir (no symlink race), radcli handle lifetime is right (every early return calls rc_destroy, send/received freed once, no double-free/UAF), BSD+GNU make include syntax OK, nothing dropped from the removed Makefile detection. configure passes sh -n and dash.

[BLOCK] M1 - lib/vendor.h + Makefile `-include config.mk` / BSDmakefile `.sinclude`:
  Shipped defaults flipped #define -> #undef AND a missing config.mk is silently ignored. Plain `make` with no ./configure (packagers, old scripts, muscle memory) builds with NO Cancel-Lock, NO DB, NO zlib, no error. With the default `readercanlock require-auth` that build refuses every cancel/supersede. Make an absent config.mk a hard error: `ifeq ($(wildcard config.mk),)` -> `$(error run ./configure first)` + BSD equivalent; allow only clean/distclean without it.

M2 - configure trap + final `cmp -s ... || cat "$cur" > "$vendor"`:
  `trap 'rm -rf "$tmp"' EXIT HUP INT TERM` removes $tmp but does not exit, so the script runs on after Ctrl-C/SIGTERM and can `cat > vendor.h` after already truncating it to 0 bytes (reachable via --without-zlib). Fix: `trap 'exit 1' HUP INT TERM` + separate `trap 'rm -rf "$tmp"' EXIT`, and write vendor.h via a temp file + mv (as build-on-host used to).

M3 - configure set_option ignores its return: if the #define/#undef line is missing it prints "not changed" and carries on; report says "on", config.mk gets flags, vendor.h stays off, exit 0. Treat failure as rc=1.

M4 - configure rewrites git-tracked lib/vendor.h every run -> dirty tree, pull/rebase conflicts, and a hand-set option (e.g. #define RADIUS_ENABLED with a nonstandard lib) is overridden. Design cost; consider a separate generated config.h included from vendor.h, or document in INSTALL that configure owns these 10 options.

LOW (security-relevant) 11 - dreaderd/dns.c radiusAuthenticate: a Filter-Id longer than DEFNAMELEN makes rc_avpair_tostr return nonzero and the code falls back to "100 Success" - silently granting the DEFAULT readerdef instead of the intended one. Fails OPEN. Fail closed or log. Also ERROR/BADRESP/TIMEOUT all collapse to one "error" line; rc_auth msg not logged.

LOW portability (configure): illumos `sed -E` and `find -maxdepth` can silently fail (feeds M3 / falls back to the compiled-in radcli dictionary path); db5-header-vs-db4-lib pairing in probe_db; `strchr(w[1], ':')` misreads an IPv6 literal as host:port in radiusConfig; CC not written to config.mk so `CC=clang ./configure && make` probes with clang but builds with gcc; probe_canlock links only cl_get_key so a 3.0-3.2 lib passes the "3.3+" claim. Stale text: codeql.yml comment still says "RADIUS off in lib/vendor.h".

================ PR #169 (Perl auth + htpasswd, stacked on #167) ================
Clean: no auth bypass in password_ok/checkuser (empty/short hash, unknown user, ':' or newline in username all refuse), no overflow in perlWords (inputs bounded by au_Perl[255]) or the 16-entry table, PERL_SET_CONTEXT correct, D-167 fix (one interpreter per perl line) works as the test shows, apr1 reads correct vs the reference.

[BLOCK] H1 - contrib/htpasswd-auth.pl re-reads + reparses the WHOLE file on every login, no cache. Auth runs synchronously inside a dns worker (PerlAuthenticate off the dns loop ~2335), so one worker serves logins serially. An unauth client looping `AUTHINFO USER nobody / PASS x` - unknown user always scans the full file - stalls that worker's whole queue, including connection-time DNS lookups. 100k-entry file ~50-100ms CPU/login on top of the hash cost. Trivial DoS. Fix: per-interpreter cache (each perl line already has its own interpreter, so `our %USERS; our ($MTIME,$SIZE,$INO)` is naturally per -f file); stat() each login, reload only if (mtime,size,ino) changed (ino matters - htpasswd rewrites by rename); slurp+parse so a half-written file is not read; stat-fail/gone -> drop cache + refuse. Workers are separate single-threaded processes, so no locks.

M2 - dreaderd/dns.c call_checkuser (~1525) uses call_argv(..., G_SCALAR, ...) with NO G_EVAL: a runtime `die` in checkuser longjmps with no JMPENV -> perl exit()s the whole worker, losing all in-flight requests. Same failure mode this PR removes for LOAD-time errors, left open at login time. Fix: G_SCALAR|G_EVAL, check SvTRUE(ERRSV), refuse + log; better, wrap checkuser body in eval{}.

M3 - interpreter table: 16 entries, never evicted, a failed one is sticky forever (a fixed-on-disk script needs a worker restart); 254-char config value truncated silently by strncpy (~2933) - a long path/unbalanced quote becomes a wrong word with no warning. Log it.

LOW 7 - user enumeration by timing: unknown user returns after the scan with no hash computed; known user pays 1-3ms (apr1) to hundreds of ms (bcrypt). Remote timing distinguishes valid usernames. Fix: dummy-hash compare for unknown users (cheap once H1's cache exists).

LOW - htpasswd.pl details: perlWords `"` toggles quote-state mid-word with no escape and an unterminated quote swallows to EOL; apr1 salt regex `{0,8}` silently falls through to crypt() for >8-char salts (safe, undocumented); DES crypt compares only 8 chars (documented - recommend warning + preferring $apr1$/bcrypt); with --plaintext on, a `*`/`!` lock marker becomes a literal password (reject those even in plaintext mode). `my ($a,$b)` in `same` masks sort vars (cosmetic).

LOW tests (htpasswd_auth_test.go): only one apr1 vector (add empty/short/long salt + >16-char pw); no cache test (add once H1 lands: same-second same-size edit, rename-replace, truncate-in-place); the write() helper replaces the file non-atomically (os.WriteFile) - a reader can see a truncated file mid-write, a possible flake now and a real race in production without a cache; bcrypt/yescrypt->crypt() path untested on FreeBSD/SmartOS (add an explicit "unsupported hash refuses" test); >16 distinct perl lines (table-full path) untested; runtime-die-in-checkuser untested (M2).
