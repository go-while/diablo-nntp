[Claude] Thanks for the thorough review. **#259** is updated (head f6482c8: two fix commits plus a merge of main e5934a7, no force-push): https://github.com/jrehmer/diablo-nntp/pull/259

1. **Verify cache:** gone. lib/pgp.c gains PGPSigner(), which runs pgpverify once per message and returns the signer, or the failure and whether it could not check at all. Each verify line compares the signer with its key. dgpverify (not implemented) always fails closed. Test: TestCheckgroupsVerifyDgpBlocks, with the real ISC message.
2. **Sender:** one address, from Sender: (else From:). That is the address in <...>, else the first word that is not a (comment), matched in lower case against the lowercased <from>. CtlFromMatches stays only for ParseControl (log/mail of the other types). Test: TestCheckgroupsSenderAddress (two addresses in From:, a comment, Sender: in mixed case).
3. **Wording:** comments and samples now say "as INN documents", plus a note that INN 2.7's docheckgroups also removes groups that a later line covers.
4. **Unknown action:** the line is ignored, with a logit() warning. A line with only `break` adds no rule but still ends the scan.
5. **Fail closed:** pgpverify not runnable, its exit status 2, no PGP support, or dgpverify: the line leaves its groups alone, as a log line does. A missing or bad signature still skips the line, as INN's pgpfail does.
6. **maxcheckgroups:** keeps its old meaning when no /maxdocheckgroups/ line matches the sender: the line for the first group of the message limits all its changes. The sample example now lists all eight Big-8 hierarchies; the README and changes note are updated.
7. **Logs and mail:**
   - "processing failed" when no line acted.
   - A line's own =xxx log gets its pass, with the article. It is opened only when the line has groups to act on, so the samples' catch-all `all:*:*:log=control.log` stays quiet (TestDcontrolSampleCheckgroupsLog passes).
   - Mail goes out when any matching line has mail, drop and failed verify included.
   - A temp log made in CgRun now starts with the article.
8. **Out of memory:** CgReadRules, CgAppend, CgLocalGroups and CgCheck report it, and the whole checkgroups stops.

- TestCheckgroupsLineMatching (unknown action, break, another sender, a line's own log)
