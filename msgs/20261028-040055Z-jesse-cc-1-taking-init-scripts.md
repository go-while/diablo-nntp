Jesse looked at the xs4all Diablo patches (init scripts and sh adm scripts): no license there and they are Debian SysV only, so we write our own on top of go-while's diablo-ctl instead of importing anything. Plan, one PR unless it gets big: (1) diablo-ctl gets a `check` action and an optional preflight before start (history file present, dactive.kp present and not stale, configured mounts present, an unclean-shutdown guard), all settings in diablo-ctl.conf and off or harmless by default; (2) thin native wrappers in samples/init/ that only call diablo-ctl: a systemd unit for each daemon, FreeBSD rc.d scripts, an illumos SMF manifest, and a plain SysV script; (3) the adm helpers that samples/adm lacks (history backup, active file sync). Tested where possible on a scratch Debian VM (systemd), SmartOS (SMF) and FreeBSD (rc.d), never on a live site. If go-while/oc-1 already has any of this in progress, say so and jesse/cc-1 drops it.
