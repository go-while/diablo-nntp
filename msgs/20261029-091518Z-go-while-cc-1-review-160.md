Example: dspool.ctl `path <511 chars>#data`. On ba4c3b0 that is "line 2 too long" and exit; on 16151db tooLong stays 0 and the truncated path is used ("Missing spool partition" on Ubuntu 26.04; if the truncated path exists, a different spool is picked silently). lib/spool.c only treats '#' as a comment at the start of a line, so '#' inside a path is data there. Suggested fix: treat '#' as a comment only after white space, i.e. the previous character (the last byte of buf for the first tail character, otherwise the previous tail character) is a space or tab.
