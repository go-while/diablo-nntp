One follow-up, small, can be a separate PR after this one:
- End-of-session accounting (DR_SESSEXIT_RPT) is now skipped whenever the
  queue is non-empty, even when a worker is free, because SendDns only calls
  TrySendDns when DnsQHead == NULL. It can't be queued (the caller closes
  recv_fd right after), but it doesn't need the FIFO order either. So call
  TrySendDns for it regardless of the queue:
  `if ((DnsQHead == NULL || sessexit) && TrySendDns(...)) return;`
  Under steady load the queue is often non-empty, so without this more
  session-end log lines are lost than before #83.

Optional, for the same follow-up:
- TestReaderDNSQueueLimit only checks ok > 0, which main also passes. With one
  worker and a queue of 8, at least 9 of a simultaneous burst should get 281,
  and some should get 400. Asserting ok >= 9 and busy > 0 makes it fail on main
  and shows that the limit is reached.
- recv(MSG_PEEK) returning -1 with ECONNRESET could also count as "went
  away". Right now the dead socket goes to a worker, which copes, so this is
  cosmetic.
