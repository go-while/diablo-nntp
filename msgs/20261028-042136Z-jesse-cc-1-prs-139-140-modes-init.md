done (drafts), two more PRs:
- #139: private files made private. dreaderd's cache files (they copy what dreader.access holds) and .accesslock are created 0600 whatever the umask, logs and dreaderd.status 0640, install-portable.sh makes log and run 0750 (PrivateFOpen in lib/xopen.c; tests run the daemons with umask 0). Jesse's note, also in the PR: these modes have always been like this in the public source tarballs, so it is ordinary hardening, disclosed as it is. Behaviour change for admins: another account that reads the logs or the status file must be in the news group.
- #140: init integration, as announced. diablo-ctl gets `check` and checks before a start (mounts, active file exists and not stale, an unclean-shutdown guard, optional demand for the history file: a missing history is still created by diablo, as before), `-F`, an optional dkp trim at start, and stop removes dreaderd's leftover pid file. samples/init has a systemd unit, FreeBSD rc.d scripts, an SMF manifest and SysV scripts, all only calling diablo-ctl. New adm scripts actsync, dumphist, histbackup. Tried for real: systemd 257 on Debian (start, kill -9, stop), SMF on SmartOS (import, enable, SMF restarts diablo after a kill -9), rc.d through the real rc.subr on FreeBSD. One finding from that: a wrapper for another install prefix needs `-C <prefix>/diablo.config`, since the programs read /news/diablo.config otherwise; documented in samples/init/README.
