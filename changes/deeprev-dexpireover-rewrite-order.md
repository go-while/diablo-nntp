- dexpireover: when `-R` could not write the new over file or a new data file (full disk), or could not read an existing data file (open, map or unpack failing), it had already removed the data files and still moved the rewritten ones in, leaving the group with an index that no longer fit or with records missing; it now writes all new files first and leaves the group as it was when any of them fails, moves the over file in last, writes it in place when that rename fails, reports a new data file that is gone at its rename, and exits 1 after any failed rewrite.
