- `contrib/xtrace/decrypt-aes.sh`: `-m '<message-id>'` reads the article from this server's spool (`dreadart -h`) instead of stdin, and without a password the script tries every `cryptpw` of dreader.access (`<dpath lib>/dreader.access`, or `-a file`), so `decrypt-aes.sh -m '<id>'` run as news is enough. The password argument (`pass:`, `env:`, `file:`) still works. A decrypted value must be readable text, so a wrong password that passes the padding check by chance is not shown as a result. dreadart and dpath are found next to the script, in the PATH or in /news/dbin.
