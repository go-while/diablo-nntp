- `dexpire`: a running `dhisexpire` that installs a new history mid-run no longer gets the expired flags written into the old (dead) file: dexpire notices that the path no longer names its open descriptor and stops, asking to be run again. The spool directories of that run are already removed, so the new history keeps their entries live until the next dexpire run repairs them.
- `diablo`: `hiscachesize` must be a power of two; a value that is not stops at config load instead of leaving the precommit cache only partly reachable.
- `diablo`: `HistoryOpen` refuses a history whose header entry size does not match this build, or whose header is smaller than this build's, instead of walking the records at the wrong stride (a larger header stays allowed: the hash table is mapped at its size).
- `diablo`: a `PC_DELCOMM` for a message-id whose hash slot holds a different message-id leaves that entry alone, so the other article's precommit/postcommit cache entry is not evicted.
