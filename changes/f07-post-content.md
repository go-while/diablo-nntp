- `dreaderd`: POST preserves a supplied `Lines:` header and no longer generates one by default (RFC 5536 3.3.1; RFC 5537 3.5 step 6). Explicit `rfc5537 no` or `legacytrace yes` keeps generating it when absent; a supplied header is preserved in every mode. The overview line count still comes from the body count carried by the feeder and header feed (D-174), independently of this header.
- `dreaderd`: the obsolete vserverdef option `posttrailer` is accepted but ignored in every mode, with one warning per access-file read. It no longer appends text to a POST body (RFC 5537 3.5 step 6); old access files still load. There is no opt-in to body modification.
