- New `dbin/djoblog job command [args]` runs a cron job and writes its output to `<path_log>/<job>.log`, a time stamp (as in the other diablo logs), the job name and the process id on every line, with BEGIN and END lines (the END line has the exit status). `djoblog -s` logs to syslog (facility news) instead, `-f file` names the file. The exit status is the command's. The log is opened for each batch of lines, so it can be rotated while the job runs. `adm/crontab.sample` runs every job under djoblog, and `adm/daily.atrim` rotates the job logs (`hourly.expire.log`, `daily.atrim.log`, `biweekly.atrim.log`, `daily.reader.log`, `weekly.reader.log`, `actsync.log`, `histbackup.log`); `daily.log` is still rotated for a crontab that writes it. To use it on an installed site, change the crontab to the entries of `adm/crontab.sample`, and install the new `daily.atrim` (an installed script that was changed is kept, the new one is installed as `daily.atrim.new`).
