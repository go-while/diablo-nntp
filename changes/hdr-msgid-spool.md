- `dreaderd`: `HDR` and `XHDR <header> <message-id>` now fall back to an asynchronous spool `HEAD` when the current group's bounded overview lookup misses, so they cover articles in other groups and work without a selected group, including articles with no local overview. HDR outputs `0 <value>`, XHDR `<message-id> <value>`; field-name matching, folded values and absent-field output use the existing overview formatter. An unknown article is 430; metadata (`:bytes`/`:lines`) unavailable outside that overview path is 503. The group/current article, `OVER`/`XOVER` scope and capabilities are unchanged. Partial HEADs are not cached as articles; buffering is capped at 1 MiB and oversized responses are drained before 503 (ISSUES.md D-193).
