- dexpire: the history update of a second or later pass over the spools now uses only the directories that pass listed. Before, the list of the earlier passes was kept, so a directory listed in pass 1 and removed in pass 2 kept its history records valid (not expired) until a later dexpire run updated the history (one that removes a directory, or `-h1`): dilookup and the feeder's `whereis` still gave those articles, whose files were gone (D-267).
