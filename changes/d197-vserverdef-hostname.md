- dreaderd: a `vserverdef` in dreader.access without a `hostname` line (also `vserverdef DEFAULT`) now serves as the host given with `-h` (else the system's host name), its cluster name is that host, and its newsadmin defaults to dreaderd's (`-A`, else news@host), as the built-in DEFAULT does; before, the host name was empty (`200  NNRP Service Ready`). A vserverdef without a `newsadmin` line now gets news@ its hostname, as samples/dreader.access says ("Defaults to news@hostname"); before, it had none, so banners and refusals now end in " - news@host". Configurations without a hostname now also get that host in front of Path and in Xref of the articles they serve (turned off with `noreadpath` and `noxrefhostupdate`), and their hashed NNTP-Posting-Host values change (with a `cryptpw`, the key was the empty cluster name), so old and new hashes of the same client differ (D-197).
