- dreaderd: a `vserverdef` in dreader.access without a `hostname` line (also `vserverdef DEFAULT`) now serves as the host given with `-h` (else the system's host name), its cluster name is that host, and its newsadmin defaults to dreaderd's (`-A`, else news@host), as the built-in DEFAULT does; before, the host name was empty (`200  NNRP Service Ready`). Such configurations now also get that host in front of Path and in Xref of the articles they serve (turned off with `noreadpath` and `noxrefhostupdate`). A block with its own hostname is unchanged (D-197).
