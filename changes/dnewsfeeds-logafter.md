- dspoolout: new dnewsfeeds option `logafter N`, passed to dnewslink as `-l N`: the number of articles between dnewslink's "mark" status lines in the general log. 0 turns the periodic lines off (the reconnect mark and the final totals stay). Default 1000 (unchanged); a label without it takes GLOBAL's value.
- dnewslink: `-l N` logs a mark after every N offered articles; the counter started at -1, so `-l 1` logged no mark at all and the default marks came at 999, 1999, ... instead of 1000, 2000, ... The count also restarts with each pass (batch file or connlife session), like the totals; before, a later pass logged fewer marks or none.
