- `adm/daily.atrim` also rotates `general.log`, `incoming.log`, `drincoming.log`, `path.log` and `article.log`, the logs diablo writes itself. They were never rotated and grew without limit. The daemons open the new file within 10 seconds of the rename, so no restart is needed; run the script by hand once after an upgrade to be sure it works. Only logs in the `path_log` directory under their default names are rotated: if `path_generallog`, `path_incominglog`, `path_drincominglog`, `path_pathlog` or `path_artlog` points elsewhere, rot skips the missing name without an error and that log is not rotated. A crontab that starts the scripts with `for i in daily.*` also runs the `.new` files an upgrade leaves next to changed scripts: use the entries of `adm/crontab.sample`.
