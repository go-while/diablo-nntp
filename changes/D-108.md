- `dcancel -a`/`-s`: the history entries of the articles copied into a rewritten spool file are stored only after that file is renamed over the old one. A rewrite that failed half-way (a damaged article header, a read or write error, a failed rename) used to leave the history pointing at offsets of the rewritten file inside the old one, so a reader could get another article's text (the cancelled one) under a valid message-id; now the history keeps the old offsets, and a failed rename or removal is reported (D-108).
