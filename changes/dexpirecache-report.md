A new line `*       N empty files and links removed` follows the "files have been cleaned" block, which is unchanged. And a run that removed no cache file with content printed `Oldest removed file was created 0 days 0 hrs 0 min 0 sec ago` and `Newest removed file was created 20783 days ... ago` (the epoch); these two lines are now printed only when a cache file with content was removed (D-303). - `dexpirecache`: `-f` alone no longer removes the empty cache files and symbolic links more than two days old; that is now part of `-i` and happens only when `-i` applies (fewer free inodes than asked for, on a file system with an inode count), so a site that relied on `-f` alone for them must add `-i` (D-303). Test: `TestDexpirecacheReport`.
