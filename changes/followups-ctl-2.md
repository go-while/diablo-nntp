- `diablo-ctl`: a wrong setting (a number that is not one, an unknown daemon) refuses `start`, `restart` and `check`, but `stop` and `status` warn, use the default and skip the entry, so a typo in `diablo-ctl.conf` never keeps a site from being stopped; leading zeros are dropped (`DIABLO_ACTIVE_MAXAGE=08` was an octal error in the shell arithmetic); `DIABLO_NOFILE` is checked as a number; `active` in diablo.config is found in any letter case and the path is asked of `dpath` (so a `%s` in it is expanded as diablo does).
