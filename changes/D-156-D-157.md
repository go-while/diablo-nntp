- `dexpire`: a failed `statfs()` leaves the free space unknown (it counted as 1 byte, which made every `minfree` look missed and could expire down to the newest directory): `minfree` and `minfreefiles` are then not applied to that file system (a message says so), while size and age limits still are (D-156). A spool directory that could not be removed (not entered, not renamed) is no longer marked removed, so its history entries are not expired while its files are there, and it no longer makes `dexpire` scan the spool again and again; files that could not be removed are not counted as freed (D-157). An empty spool path is read as the spool home, not "/" (a guard; `LoadSpoolCtl()` turns an empty path into `P.nn`, so D-158 as described cannot happen).
