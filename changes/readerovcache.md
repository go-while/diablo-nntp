- New reader setting `readerovcache` (default 8, as before): the number of groups whose overview files each dreaderd process keeps open. A feed spread over many groups opened and closed these files for almost every article with the old fixed 8; on an archive feed over about 20,000 groups, 2048 gave about 11% more overview entries per second per process. Each process lowers the value to what its descriptor limit allows (about 2 descriptors per group, besides one per client thread and a reserve) and logs it, and an open that runs out of descriptors now closes the unused cached groups and tries once more, instead of failing the article with "400 Error writing data".
