- dsyncgroups, dclient: a reply code is the whole three-digit code followed by a space or the end of the line (NntpCode()). dsyncgroups accepts 281 to AUTHINFO USER (a login without a password, RFC 4643 2.3) and sends no password then; it ends the session on a reply to MODE READER that is neither 200/201 nor a one-line refusal, on a reply line longer than its buffer, and when 381 asks for a password it was not given. dclient takes only 205 as the answer to QUIT (after -f it first skips the unread replies to the dumped commands, up to the 205; before, it took a 238 there as a stand-in) and stops on a reply without a code.
