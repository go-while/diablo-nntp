- `dreaderd`: with `rfc5537 yes` (the default), POST refuses a physical header line longer than 998 octets, excluding CRLF, with `441 Header line too long (limit 998 octets)`. Folded fields may be longer in total if each physical line fits; the connection stays usable after refusal. Explicit `rfc5537 no` or `legacytrace yes` retains acceptance of longer headers. This is the strict posting policy for F-07 step 4; RFC 5536 2.2 permits acceptance of overlong input but forbids generating overlong header lines.
