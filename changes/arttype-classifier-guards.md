- `diablo`: two robustness completions to the article-type classifier, finishing guards begun in the arttype work above. The deferred base64 `Content-Transfer-Encoding` path now clears the default bit when it marks a binary, like the uuencode/BinHex/base64 line-count paths already do; without it an article whose only binary signal is the CTE and whose blank line is the last classified line (an empty body) was returned as base64+binary with the `ARTTYPE_DEFAULT` bit still set. And `classifyLineAsTypes()` guards the second newline strip, so a one-byte `"\n"` line is not reduced to zero length and then read at `ptr[-1]`. Test: `TestArticleTypes` (the `base64 CTE, empty body` case).
