- `diablo`: a line made only of hex digits is no longer taken for base64 (or BinHex) when the article type is worked out. A SHA-256 digest is 64 hex characters, which is within the base64 line length, so a list of nine digests (a release announcement with checksums, `sha256sum` output without file names) made the article a binary and the sample `IFILTER` (`delgroup *.bina*`) refused it outside binary groups. Real base64 or BinHex data is never made of hex digits alone, so binaries are detected as before. Tests: `TestArticleTypes` (the digest cases), `TestChecksumListNotRejectedAsBinary`.
