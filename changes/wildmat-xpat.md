- dreaderd/XPAT: an unterminated `[` class in the pattern no longer reads the byte past the NUL, and a trailing `-` no longer makes the range branch step onto the NUL and walk until a 0 or `]` byte; such a class now matches nothing. No well-formed pattern changes. The measured 70 pattern/text pairs that flip are malformed classes ending in `-`, and other unterminated classes (e.g. `[]`, `[a`) whose old result depended on the byte past the NUL now deterministically do not match.
