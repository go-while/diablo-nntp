- diablo: when the host cache is rebuilt (diablo.hosts or dnewsfeeds changed, or the hourly `hostcacherebuildtime`) and the lookup of a peer given by host name gets no answer (resolver down, timeout, server failure), the addresses that name had in the previous cache are kept, and the general log says so (`host cache: <name>: <reason>, N previous address(es) kept`). Before, the name got no record at all, and that peer was refused (`502`) until the next rebuild, up to an hour, although DNS came back a moment later. A name that does not exist (no such name, no address) is dropped as before, and so is a peer no longer in the configuration (D-236).
