- `dreaderd`: RFC-mode POST preserves valid supplied header text, order and folding, including To/Cc and Newsgroups when optional legacy cleanup code is built in (RFC 5537 3.5 step 6). The Path and generated injection fields retain their existing special handling; no vendor switches are changed.
- Supplied Lines must be a single decimal number with optional surrounding spaces/tabs, no folding/comments and no duplicate field (RFC 5536 3 and 3.3.1). Invalid Lines or an empty Distribution is refused with 441 instead of accepted or silently removed. Explicit `rfc5537 no` / `legacytrace yes` retains the old acceptance and cleanup behavior.
