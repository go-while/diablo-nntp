- dexpire: a spool directory that `opendir()` or `readdir()` cannot read (an I/O or permission error) no longer counts as an empty one. Before, the history records of the articles below it were marked expired, and the feeder answered 430 for articles that were still stored. Such a directory now leaves those records as they are for that run (the other spools' history is still updated), and after a `readdir()` error nothing more is removed from it or from the N.xx directories below it. A directory that is gone (ENOENT, ENOTDIR) still counts as empty (D-268).
