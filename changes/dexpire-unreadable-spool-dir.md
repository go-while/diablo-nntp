- dexpire: a spool directory that `opendir()` or `readdir()` cannot read no longer counts as an empty one. Before, every history record of the articles below it was marked expired, and the feeder answered 430 for articles that were still stored. Such a directory now leaves those records as they are for that run (the other spools' history is still updated), and after a `readdir()` error nothing is removed from it (D-268).
