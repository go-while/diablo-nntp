- dreaderd: a failed rename or a write error (disk full) while installing the access cache files went unnoticed, and short files could replace the cache in use; a failed rename also left new files next to old ones, which the readers then loaded as one set. The old cache is now kept on a write error; a file in use that cannot be kept as a link stops the install before anything is renamed; when a rename fails the files already renamed are put back and no new cache is announced, and if that fails too the lock file (or, if it cannot be removed, its stamp) and the files are removed (each failure logged) so that no process loads a mixed set. The install is tried again. A crash in the middle of the renames is not covered.
