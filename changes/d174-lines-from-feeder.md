- The reader's overview `:lines` (the 8th OVER/XOVER/XZVER field, `HDR :lines`, `XHDR Lines`) is now the number of body lines, as RFC 3977 8.4.2 requires, instead of the article's `Lines:` header, which is empty for an article without one and can be wrong (D-174). On a full feed dreaderd counts the lines itself; on a header feed `dnewslink -H` sends the count with the size, as `Bytes: <size> <lines>`. dreaderd keeps it in the overview record's spare field (the file format is unchanged), and does not store the Bytes: line as a header, so clients never see it. Records written before, and header feeds from an older dnewslink (`Bytes: <size>` alone), keep the `Lines:` header. An older dreaderd reads the size alone from the new Bytes: line.
- `dnewslink -L` (`genlines`): the generated `Lines:` count no longer includes the final "." line of an article stored in wire format.
