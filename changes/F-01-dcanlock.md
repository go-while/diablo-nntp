- dcanlock: a new program that prints the Cancel-Key (like INN's `gencancel -k`) and Cancel-Lock for a Message-ID from the `canlockadmin` / `canlockuser` secrets of a vserverdef, writes a whole cancel article with the admin key (`dcanlock cancel`, like `gencancel`), and checks a key against a lock (F-01).
- `dcanlock cancel` writes CR LF line ends (the article goes into a POST as it is; the body is one line that does not start with a dot), stops with an error when the article's Newsgroups list does not fit instead of writing a cut list, finds `dreadart` in the directory it was found in itself when started through `PATH`, and with `-S -A file` honours the `canlocksha1` line of the vserverdef.
