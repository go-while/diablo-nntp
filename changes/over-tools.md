- doverctl: `convert` also moves the compressed (`.gz`) overview data files and stops a group, without reporting it converted, when a file cannot be moved (also with `-m`); `clean` removes unknown entries by their real path, counts only files it really removed, and uses dexpireover's criteria for stale data files (misaligned, empty range). The entry count of the old over file is read before it is moved.
- dexpireover: with `-p`, only workers that were started are waited for (a failed fork no longer makes the parent spin; it reports the missing workers and exits 1); the compression summary counts only files that were compressed, reports failures, and a dry run (`-n`) says how many would be compressed.
