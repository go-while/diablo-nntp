- diablo: after a short write to a queue file that could not be taken back, the retry writes only the rest instead of the whole buffer again. If the file then ends inside a line, the rest goes to that same file even after `dspoolout` renamed it; if the file was removed in the meantime, the whole line and the lines after it are written to the current queue file. This is not a guarantee: a file removed in the moment between diablo's check and its write still takes the rest of the line with it, and that entry is lost without a log line.
