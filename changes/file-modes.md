- File modes: dreaderd's cache files (`cache.*`, which copy the AUTHINFO passwords, `cryptpw` and Cancel-Lock secrets of dreader.access) and `.accesslock` are created 0600 (a stricter umask can only narrow that, never widen it); the logs (`lib/log.c`, dnewslink's feedlog, dcontrol logs) and `dreaderd.status` 0640; `install-portable.sh` makes `log` and `run` 0750. Other users, and monitoring that reads these as another user, lose access: `chgrp`/`chmod` them if that is wanted. Existing log files keep their mode (the 0750 directory covers them).
