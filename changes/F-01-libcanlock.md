- Cancel-Lock now uses libcanlock (3.3.0 or later) for its computations, the library INN uses, instead of its own OpenSSL code. `CANLOCK_ENABLED` in `lib/vendor.h` (on by default) turns it on; without the library no Cancel-Key can be verified: the default `readercanlock require-auth` then refuses every cancel and supersede (dreaderd logs a warning at start; `readercanlock all` executes them unchecked, as before). Install `libcanlock-dev` / `libcanlock`, or `#undef CANLOCK_ENABLED`.
