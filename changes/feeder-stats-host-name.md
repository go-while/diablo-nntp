- feeder-stats.pl: the outgoing feeds were missing from the report on a host whose name contains "diablo" (diablo1, diablo-reader, ...). The script took every syslog line of such a host, dnewslink's too, for a line of diablo, because the host name is part of the line; the lines with the outgoing statistics were never read. It now looks at the process that wrote the line (`diablo[123]:`, `dnewslink[456]:`, `dreaderd[789]:`). It is the `name[pid]:` tag after the time, with or without a host (a syslog that writes no host, Solaris' `[ID ...]`, a time with fractions of a second); the lines of dreaderd's children (reader, feed, reader-dns, reader-sdns) count as reader activity. New test `contrib/feeder-stats/test-host.sh`. The perl scripts of contrib/feeder-stats start with `#!/usr/bin/env perl` (it was /usr/bin/perl, which FreeBSD does not have, and /usr/local/bin/perl); diablo-stats.sh and cyclone-stats.sh add /usr/local/bin and /opt/local/bin to the PATH, which cron does not have.
