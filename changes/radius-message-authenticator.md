- dreaderd: with libradius (FreeBSD, SmartOS) every RADIUS Access-Request carries a Message-Authenticator and an Access-Accept without one is refused ("radius: Access-Accept without Message-Authenticator, login refused"); libradius checked one that was there but accepted a reply without it (Blast-RADIUS, CVE-2024-3596). radcli 1.4.0 and later do the same by themselves. ./configure turns this on only where libradius has `rad_put_message_authentic()` (FreeBSD; not the old pkgsrc libradius of SmartOS, where dreaderd logs a warning once and works as before). A libradius built without OpenSSL cannot add it, and then no RADIUS login goes through. Test: `TestReaderRadiusMessageAuthenticator`.
- SmartOS: `compat/srandomdev.c` (for pkgsrc libradius, which takes the Request Authenticator and the request identifier from `random()`) fills the whole `random()` state from `arc4random()`, as FreeBSD's `srandomdev()` does; it seeded only a 32-bit value.
