- dreaderd: with libradius (FreeBSD, SmartOS) every RADIUS Access-Request carries a Message-Authenticator and an Access-Accept without one is refused ("radius: Access-Accept without Message-Authenticator, login refused"); libradius checked one that was there but accepted a reply without it (Blast-RADIUS, CVE-2024-3596). radcli 1.4.0 and later do the same by themselves. A RADIUS server that does not send it (FreeRADIUS before 3.2.5, or with it turned off) no longer logs users in. ./configure checks that libradius has `rad_put_message_authentic()`; with one that has not (the pkgsrc libradius of SmartOS) dreaderd refuses every RADIUS login ("radius: this libradius cannot add a Message-Authenticator, RADIUS login refused"), so RADIUS on SmartOS needs radcli 1.4 or later (from source) or a newer libradius. A libradius built without OpenSSL cannot add it either, and then no RADIUS login goes through. Test: `TestReaderRadiusMessageAuthenticator`.
- SmartOS: `compat/srandomdev.c` (for pkgsrc libradius, which takes the Request Authenticator and the request identifier from `random()`) fills the whole `random()` state from `arc4random()`, as FreeBSD's `srandomdev()` does; it seeded only a 32-bit value.
