- diablo: new diablo.config option `feederlogfrequency n` (also `dicmd config feederlogfrequency n`): the number of articles an incoming connection receives between its status lines in the general log ("<host> secs=... ihave=..." with its spoolstats/rejstats/store lines), and the number of accepted articles between the master's "DIABLO uptime=..." lines. It was fixed at 1024, which gives a lot of lines on a busy server. 0 logs a connection's status only when it ends. Default 1024 (unchanged). Like INN's incominglogfrequency.
