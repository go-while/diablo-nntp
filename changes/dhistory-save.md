- New diablo.config option `path_dhistory_save`: a directory for the copies of the history that the adm scripts make, for a history on a RAM disk. `adm/dumphist` (run by `dicmd dumphist`, see `adm/histbackup`) keeps `dhistory.snp`, `dhistory.old` and its temporary copy there, and `adm/biweekly.atrim` has `dhisexpire -a -m -o` make the backup of the old history there; `diablo-ctl` looks for the snapshots there too. Before, all of them were next to the history, so a RAM disk held the history several times over (the history, `.snp`, `.old`, and `dhistory.bak`, which kept the old history in memory until the next trim). The default `NONE` keeps the old behaviour. `dpath dhistory_save` prints the directory.
- `dhisexpire -m` links the new history into place when it is on the history's filesystem, and copies it only when it is on another one; it prints which it did. Before, `-m` always copied, which made one more history-sized file next to the history. While dhisexpire runs, a RAM disk still holds both the old and the new history: the diablo processes keep the old one open until they switch.
