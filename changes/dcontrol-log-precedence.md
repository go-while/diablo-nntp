- samples/dcontrol.ctl (and the reader and feeder+reader samples): the leftover best.net line `all:*@*:best.*:log=control.log` is removed. Its `best.*` pattern is only tested for newgroup and rmgroup, so it matched every other control message with an `@` in the sender, e.g. every checkgroups, and moved its log from `checkgroups.other` to `control.log`. The header now says that the last `=log` among the matching lines decides where a message is logged, and that a catch-all `all` line belongs before the lines of the message types. Existing `dcontrol.ctl` files are not changed: delete the `all:*@*:best.*` line there if you use it.
