- dcancel: `-s` and `-a` rewrite spool files of a compressed spool object (dspool.ctl `compresslvl`). Before, dcancel stopped with "Compressed spools are currently not supported" and cancelled nothing there; its code for compressed articles was compiled out. A kept compressed article is copied as stored; only its Message-ID is uncompressed (with diablo's `SpoolGunzip()`, now in lib/dgzip.c). A build without zlib says that it needs zlib.
