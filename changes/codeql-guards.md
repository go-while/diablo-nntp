- Defensive CodeQL bounds: Unix-socket paths are copied with a size check that fails loudly instead of truncating, the remaining fixed-buffer copies use the destination size (`diablo_strlcpy`/`snprintf`), log/queue/temp files are created with explicit private modes (0640, spool dump 0600, `O_EXCL` for predictable names), and spool-header, history and reader-fork allocation sizes are range-checked before allocation.
