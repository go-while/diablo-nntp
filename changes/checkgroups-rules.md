- `dreaderd`: a checkgroups control message uses `dcontrol.ctl` the way INN documents `control.ctl`. The sender is one address, from Sender: (else From:), in lower case, as INN's controlchan reduces it. Every checkgroups (and `all`) line that matches it is used, not only the last one; a line with an unknown action is ignored, with a warning. They are taken from the last line to the first, and a line acts on the groups that match its pattern and no later line's, so a later line wins. `doit` and `verify-*` lines check their groups, as before. pgpverify runs at most once per message, and each `verify-*` line compares the signer with its key. A line whose signature is missing or bad is skipped as if it were not there; one whose signature cannot be checked at all (pgpverify not runnable or its exit status 2, no PGP support, `dgpverify`, which is not implemented) leaves its groups alone. A `drop` line leaves its groups out of the list, so an earlier `doit` line removes those that exist (INN's `checkgroups:*:*binaries*:drop` example). `log` and `mail` lines change nothing and write their lines of the message to the control log. The change limit takes INN's syntax, `/maxdocheckgroups/:<from>:<newsgroups>:<number>`, and each change counts for the last such line that matches its group. When no `/maxdocheckgroups/` line matches the sender, `maxcheckgroups:` lines keep their meaning (the line for the first group of the message limits all its changes). A line's own `=xxx` log gets what that line does; mail is sent when any matching line asks for it; a message on which no line acted is logged as failed; running out of memory stops the whole checkgroups. A site whose checkgroups lines are all `drop` still never has its groups changed. The tests of the earlier checkgroups change are renamed `TestCheckgroups*` (tests/e2e/checkgroups_docheck_test.go). New tests: `TestCheckgroupsEveryLine`, `TestCheckgroupsLaterLineWins`, `TestCheckgroupsDrop`, `TestCheckgroupsAllDrop`, `TestCheckgroupsVerifySkipped`, `TestCheckgroupsMaxdocheckgroups`, `TestCheckgroupsVerifyTakesGroups`, `TestCheckgroupsVerifyDgpBlocks`, `TestCheckgroupsSenderAddress`, `TestCheckgroupsLineMatching`.
