- dreaderd: the NEWNEWS group list is a wildmat as in RFC 3977: `!pattern` excludes groups (it was taken as a group name, so the groups were listed), the last matching pattern decides, and a group matched by several patterns is listed once (its message-ids were printed once per pattern). Plain group names in a list that also has wild patterns (`*`, `?`, `!`) are looked up by name for each group of the active file, not matched against every group one by one, so a client line of 110,000 names and one `*` no longer holds the reader process for tens of seconds.
