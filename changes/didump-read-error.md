- didump: a read error in the middle of a dump no longer ends the dump as complete. didump printed "Error reading file" but still wrote the closing "." line and exited 0. After a read error (and when it cannot allocate its read buffer) the "." line is left out and didump exits 1 (D-287). Note: diload accepts a dump without the final "." by design, so a `didump | diload` pipeline must check didump's own exit status, for example with `set -o pipefail` in a shell that has it. The old csh sample `samples/adm/old.biweekly.atrim.dexpire` checks only diload's `$status`, so it does not see this failure.
