- dreaderd: GROUP, LISTGROUP, NEWNEWS, the overview and article commands and cancel lookups no longer create the over.* overview index of a group that has none (with its directory, the article slots and two fsync() calls); a missing index file is taken as a group without articles, and the feed creates it with the group's first article. On main one `NEWNEWS *` created an index for each matching group that never had an article, and a client that selected the groups of the active file one by one did the same (D-223). The 211 reply of GROUP and LISTGROUP changes for a group with a missing index (lost, or never created while its active range is not empty): the low number and the count follow max(NB, NE-1024), where main gave max(NB, NE-A) from the index it had just created, A being the initial index size (the dexpire.ctl `a` option, 512 by default). dcancel -r and dgrpctl masscancel keep their own copies of the old open and are not changed here.
