- dexpire: a trailing slash in `path_spool` or in a spool's `path` in dspool.ctl (`/news/spool/`, `P.01/`, also doubled) no longer makes dexpire mark every history record of that spool expired. Spool paths are kept without trailing slashes, and the spool home is compared without them, so the directory names dexpire builds from the spool path match those it builds from the history (D-239). A spool path `/` gives `/D.x` (with spooldirs `/N.00/D.x`), not `//D.x`; with `path_spool /` every absolute spool path is taken as below the spool home.
- Behaviour change: in dspool.ctl, `path <spool home>/` (the spool home spelled with a trailing slash) on a spool other than 00 now means the spool home itself; it used to become `P.nn`. Articles an older build stored in `P.nn` under that spelling are then looked for in the spool home: move them, or write `path P.nn`.
