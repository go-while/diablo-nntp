- dexpire: a trailing slash in `path_spool` or in a spool's `path` in dspool.ctl (`/news/spool/`, `P.01/`, also doubled) no longer makes dexpire mark the history records of that spool expired. Spool paths are kept without trailing slashes (a path `/` stays `/`), and the spool home is compared without them, so the directory names dexpire builds from the spool path match those it builds from the history (D-239). A spool path `/` gives `/D.x` (with spooldirs `/N.00/D.x`), not `//D.x`; with `path_spool /` every absolute spool path is taken as below the spool home.
- Behaviour change: in dspool.ctl, `path <spool home>/` (the spool home spelled with a trailing slash) now means the spool home itself, on spool 00 too; it used to become `P.nn` (`P.00` for spool 00). Articles an older build stored in `P.nn` under that spelling are then looked for in the spool home: move them, or write `path P.nn`.
