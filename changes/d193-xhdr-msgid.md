- `dreaderd`: `XHDR <header> <message-id>` now returns that article's header line with the message-id as the first field (RFC 2980 2.6), and `HDR`/`OVER`/`XOVER <message-id>` return the line or overview with 0 as the first field (RFC 3977 8.3.2, 8.5.2, as INN does), instead of an empty `221`/`224` list or `503`. The message-id is looked up in the current group; an unknown one (or one not in that group, or no group selected) answers `430 No such article` The lookup reads the group's article range, then walks its overview index without holding the record lock, over at most the newest 100000 articles; an older one answers 430 too (ISSUES.md D-193).
