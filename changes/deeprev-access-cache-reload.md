- dreaderd: a new access cache was loaded only when the access lock file's time was later than at the last load, in whole seconds; after the clock stepped back (or a VM was restored) later installs were not loaded until the clock caught up or dreaderd restarted, and a second install in the same second was missed. It is now loaded whenever the lock file's time (with nanoseconds where the system has them), size, inode or device differ; an empty or removed lock file, or one that cannot be looked at, loads nothing (the old map stays).
