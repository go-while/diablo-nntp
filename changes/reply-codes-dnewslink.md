- dnewslink: a reply code is the whole three-digit code followed by a space or the end of the line (NntpCode()), and only the codes the command defines count. 437 is no longer taken as an answer to an IHAVE offer or to TAKETHIS, nor 431 to TAKETHIS (the connection fails, the article stays queued). A reply to MODE STREAM or MODE COMPRESS that is neither the expected code nor a one-line refusal (480, 500-503; 403 for COMPRESS, as Diablo's feeder sends) closes the connection instead of going on without the mode on the same stream, where the lines after it were read as the next reply.
