- `dreaderd`: `readerdns` (1..1024) and `readerfeedforks` (0..1024) are checked, in diablo.config and as `-D`/`-F`; another value stops dreaderd at startup with an error instead of starting with no DNS worker (every client "400 Server too busy") or a negative fork count (ISSUES.md D-181). Upgrade note: every program reads diablo.config, so a value that was harmless on a feeder (say `readerdns 0`) now stops diablo as well; fix or remove the line. The values are decimal now: `0x10` and `010` (read as octal 8 before) are refused.
- `lib/kpdb.c`: on OpenBSD `KPDBSort()` stores the offsets with one `pwrite` per record, not through a writable map, which there could write back stale bytes over another process's field update (D-90, D-171).
- `tests/e2e`: TestKPDBTooLarge skips a subtest when the temporary directory has less free space than its sparse file: on tmpfs dkp's scan through the map allocates every page and got SIGBUS (seen on a Debian VM with a 2 GB /tmp).
