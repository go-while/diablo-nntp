- Build: `./configure` is now step one before `make`. It detects zlib, libcanlock, Berkeley DB, cdb, PAM, LDAP, Perl and RADIUS support, sets `USE_ZLIB`, `CANLOCK_ENABLED`, `DB_ENABLED`, `REJECT_DB`, `CDB_ENABLED`, `PAM_ENABLED`, `LDAP_ENABLED`, `PERL_ENABLED` and `RADIUS_ENABLED` in `lib/vendor.h` (all `#undef` as shipped now) and writes `config.mk` with the compiler and linker flags. The detection that was in the makefiles (libcanlock prefix, Berkeley DB, the RADIUS library) moved into it, `compat/detect-db185.sh` is gone, and `make` without `./configure` builds the minimal program set. PAM, CDB and LDAP now link (`-lpam`, `-lcdb`, `-lldap`); before, they could not be turned on (`--with-`/`--without-perl`/`ldap`/`radius` to force, `-n` to only report). The Makefile and BSDmakefile now add the libraries and the perl compile and link options when either is on; before, enabling them in `vendor.h` did not link.
- dreaderd: the LDAP and Perl authentication code builds again with current OpenLDAP (the synchronous calls need `LDAP_DEPRECATED`) and with a threaded perl (the interpreter is the file-scope `my_perl`, `xs_init` takes `pTHX`).
- dreaderd: RADIUS authentication also works on Linux, through the radcli library (`RADIUS_RADCLI` in `lib/vendor.h`, set by `./configure` where radlib.h is absent and radcli is installed). The `radius` file of an authdef keeps the BSD `radius.conf` format; a radcli `radiusclient.conf` is read as it is. The CI build script installs radcli and runs `./configure`, so the RADIUS tests run on the Linux distributions that have it and on FreeBSD.
