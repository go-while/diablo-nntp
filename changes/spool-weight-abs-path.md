- A spool without `weight` in dspool.ctl gets the size of its file system as its default weight. The size was asked of statfs() with the path as written in dspool.ctl (`P.01`), relative to the working directory of the program, which is not the spool directory when dspool.ctl is read: dexpire (and the daemons) logged "unable to statfs P.01 (No such file or directory)" for each spool at every run, and the weight was 1 instead of the size. The path under path_spool is used now.
